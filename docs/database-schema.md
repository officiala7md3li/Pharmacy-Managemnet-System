# Database Entity Relationships and Schema

## Core Tables
1. **Medicines**: Stores drug names, active ingredients, dosages, barcodes, and expiry dates.
2. **Suppliers**: Supplier contact information, company registers, and credit terms.
3. **Categories**: Classification of pharmaceutical products (Prescription, OTC, Supplements).
4. **SalesInvoices**: Header records for retail transactions including totals and payment methods.
5. **SalesInvoiceDetails**: Line items linking medicines with quantities and sale prices.
